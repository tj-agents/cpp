# MSVC scaffold

The standard is `../../standards/windows/SCAFFOLD.md`, shipped in this plugin.

Read it when scaffolding an MSVC project. Its bundled generator and templates are relative to that document. Preserve the requested project type and existing files; the initial template is a user-mode console application.
