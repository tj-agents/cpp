# MSVC toolchain

The standard is `standards/windows/MSVC.md` in `tomjseery/cpp-agents`, deployed to `~/.agents/standards/windows/MSVC.md`.

Read and follow it when selecting, configuring, building, or diagnosing an MSVC or clang-cl C++ toolchain. Win32 application design is owned separately by the Win32 style standard.
